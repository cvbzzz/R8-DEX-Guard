R8 DEX Guard

一个基于 Jetpack Compose 构建的 Android 应用，用于对 APK / DEX 文件进行代码混淆与保护。通过图形化界面集成多种混淆策略，帮助开发者在发布前增强应用的安全性。

---

✨ 功能特性

核心混淆（独立生效）

选项 强度 说明
控制流平坦化 ★★★★★ 打乱控制流结构，显著提升逆向难度
符号混淆 ★★★★★ 重命名类、方法、字段，去除可读性
逻辑混淆 ★★★★☆ 插入等价逻辑变换
全局状态耦合 ★★★☆☆ 将方法状态耦合至全局，增加分析成本

需配合 DEX 优化生效

· 花指令（优化时）
· 扁平化 2.0（优化时）
· 数字混淆（优化时）
· 指令替换（优化时）

基础选项

· 去除调试信息
· 加密资源 ID
· 只读取规则内类
· 不处理接口类
· 字符串加密
· DEX 优化

隐身保护

· 隐身保护（合并开关）★★★★★
· 插入虚假分支
· 字符串多层加密

🖥️ 界面说明

顶部栏

· 左侧：盾牌图标 + 标题 R8 DEX Guard
· 右侧：❤️ 赞助按钮，弹窗展示赞助信息

文件选择

· 输入文件：支持选择 APK 或 DEX 文件
  · 选择 APK 时自动提取包名，并填充到 包名过滤 与 规则 输入框
  · 选择 DEX 时进入 DEX 模式
· 输出路径：保存处理后的文件

参数配置

· 混淆深度：默认 2
· 混淆重复次数：默认 1
· 包名过滤：仅处理匹配的包
· 规则文本：类/方法匹配规则（如 com.example.**）
· 字典路径：自定义混淆字典（默认 /sdcard/dict.txt）
· 映射路径：mapping 文件保存位置

以上路径均通过 SharedPreferences（dexguard_prefs）持久化保存。

混淆选项

使用 checkboxes 列表展示所有可勾选项，分为：

1. 核心混淆
2. DEX 优化相关
3. 基础选项
4. 隐身保护

处理流程

· 显示进度条与状态文本（就绪 / 处理中 / 完成）
· 处理日志实时展示
· 完成后弹出对话框，区分成功 / 失败并展示消息

DEX 模式

当输入为 .dex 文件时：

· 加载 DEX 内的类/方法列表
· 支持多选需要处理的 DEX 名称
· 显示当前处理的 DEX 名称与方法名

🚀 快速开始

环境要求

· Android Studio Hedgehog 或更高
· Kotlin 1.9+
· Jetpack Compose
· 最低 SDK：根据项目配置（建议 24+）
· 需要存储权限以读写 APK/DEX 文件

构建步骤

```bash
git clone <repo-url>
cd R8DexGuard
./gradlew assembleRelease
```

使用流程

1. 打开应用，授予存储权限
2. 点击「输入文件」，选择 APK 或 DEX
3. 按需配置混淆选项与参数
4. 指定输出路径
5. 点击「开始处理」，等待完成
6. 在输出路径获取混淆后的文件

---

🔧 关键实现说明

· 状态管理：使用 remember + mutableStateOf 管理所有输入状态
· 偏好持久化：dictPath / mappingPath 通过 LaunchedEffect 自动写入 SharedPreferences
· DEX 模式判断：inputPath.lowercase().endsWith(".dex")
· 包名提取：选择 APK 后回调 onPackageExtracted，自动填充包名与规则
· 交互反馈：通过 onToast 回调统一弹出提示

---

⚠️ 注意事项

· 混淆前请备份原始 APK/DEX
· 部分选项需配合 DEX 优化 才能生效
· 规则为空时可能处理全部类，谨慎使用
· 处理大文件时请耐心等待，避免中途退出
